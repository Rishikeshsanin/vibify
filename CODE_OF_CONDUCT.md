# Code of Conduct

Vibify should be a useful, welcoming place to build and discuss software.

## Expected behavior

Be respectful, constructive, and specific. Critique ideas and code rather than people. Assume good intent, but communicate clearly when something is unsafe, incorrect, or harmful to the project.

Good collaboration includes:

- giving actionable technical feedback
- respecting different experience levels
- keeping issue threads on-topic
- documenting disagreements with evidence where possible
- avoiding harassment, insults, threats, discrimination, or personal attacks

## Project spaces

This applies to issues, pull requests, reviews, discussions, and other collaboration spaces associated with Vibify.

## Enforcement

Content or behavior that makes collaboration unsafe or hostile may be edited, removed, locked, or blocked from further participation at the maintainer's discretion.

If a concern involves a security vulnerability, use the process in [`SECURITY.md`](SECURITY.md) instead of discussing sensitive details publicly.
